## [0.1.0] - 2026-10-11
### Added
- **Core 3D Engine**: Procedural 5-room Victorian haunted mansion rendered in Three.js and `@react-three/fiber`.
- **Atmospheric Audio**: Web Audio API procedural 45Hz sub-bass binaural drone, heartbeat proximity radar, iron creaking doors, and multi-channel text-to-speech narrations for Ghost, Reaper, and Skeleton.
- **Multi-Language Analysis Engine**: Static analysis scanner detecting Python AST smells (bare exceptions, mutable defaults, dead code) and JS/TS smells (empty catch blocks, loose equality, leftover console.log, eval/dangerouslySetInnerHTML, @ts-ignore, and deep nesting).
- **Server-Side Game Authority**: Idempotent click evaluation, 4-candle lifelines, 4-visit lantern limits, and quantized warmth calculation (`/api/warmth`).
- **Investigator UI**: Gothic landing screen with candle ritual, briefing lore, interactive role selection, and post-game Haunting Report with fix suggestions.
- **Offline Reliability**: Built-in sample repo cache (`sample_cache.json`) ensuring 100% offline demo execution.
- **Testing & CI**: Pytest suite (32 tests) and GitHub Actions CI workflow.
